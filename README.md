# なぎ

同乗者が酔いにくい運転を、音声で支えるWebアプリです。スマホの加速度センサーとGPSで揺れを測ります。

設定で「カメラ先読み（試験中）」を使うと、前の車への接近をカメラで捉え、走行中（時速15km以上）に声で先に伝えます。映像は端末の中で処理し、保存も送信もしません。カメラの見え方や処理速度は、`camera.html` の検証画面で確かめられます。

試作段階です。判定のしきい値とスコアは実車で調整する前の初期値で、酔いを防ぐことを保証するものではありません。運転中は画面を見ないでください。

## 開発

```bash
python3 -m http.server 4173
```

```bash
npm test
```

実機のセンサーはHTTPSで配信したページでのみ使えます。センサーなしで試すときは、画面のデモ走行を使います。
